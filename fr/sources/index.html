Sources et méthodologie

HolidayMaximizer sépare les calendriers de jours fériés du droit du travail sur les congés annuels. Le classement mondial utilise une valeur normalisée de congé annuel plus une base prudente de jours fériés ; les dates exactes restent un jeu de données calendaire distinct.

Calendriers de jours fériés

Certains calendriers régionaux sont stockés localement. Une couverture plus large utilise l’API communautaire Nager.Holidays v4 ↗. Pour les années ou subdivisions non stockées localement, le planificateur interroge l’API dans le navigateur et met en cache les réponses réussies dans le stockage local afin d’éviter les requêtes répétées inutiles.

Sources vérifiées sur les congés annuels

Nous affichons désormais un équivalent sur une semaine de cinq jours pour tous les pays vérifiés du classement. Les semaines sont converties en cinq jours, les décomptes sur six jours sont ramenés à cinq jours et les périodes en jours calendaires utilisent un ratio 5/7. Cette normalisation sert uniquement à comparer les ordres de grandeur.

Base de jours fériés du classement

Le classement utilise une base numérique prudente de jours fériés afin que chaque ligne puisse être triée sans dépendre d’une API en direct. Lorsque les États, provinces, cantons ou nations diffèrent, la valeur basse/commune est utilisée et la ligne l’indique. Les dates exactes par année dans le planificateur proviennent des calendriers locaux et de l’API communautaire Nager.Holidays v4. Un jour férié ne crée pas toujours un droit légal à un congé payé pour tous les salariés du privé.

Corrections

Le droit du travail et les calendriers changent. Pour signaler une erreur, écrivez à contact@kattegatstudio.dk avec une source officielle.

Couverture mondiale des congés annuels

HolidayMaximizer privilégie la législation nationale et les autorités du travail. Pour éviter les comparaisons vides lorsque le droit primaire d’un pays n’est pas encore encodé, la comparaison/le classement peut utiliser une référence légale internationale secondaire clairement signalée. Aucun droit du pays parent n’est attribué automatiquement aux territoires et juridictions spéciales.
