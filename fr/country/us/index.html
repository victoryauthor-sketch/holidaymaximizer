Comment optimiser vos congés

Planification avec les jours fériés

  • Il n’existe pas de minimum fédéral général de congés payés: saisissez donc le nombre de jours réellement accordés par votre employeur.
  • Les jours fériés fédéraux du lundi, comme Memorial Day et Labor Day, créent naturellement des week-ends de trois jours qui peuvent être prolongés avec quelques jours de congé.
  • Les jours fériés des États et leur observation par les employeurs varient; le calendrier fédéral est une base, pas une garantie de congé.

Base légale et méthode de comparaison

Le droit fédéral américain n’impose pas de minimum général de congés annuels payés dans le secteur privé.

Contexte régional et calendrier

Le planificateur combine les week-ends avec les données de jours fériés prises en charge et peut utiliser des calendriers de subdivisions de premier niveau lorsque les données le permettent. Les jours propres à un employeur, une commune ou un secteur peuvent différer.
